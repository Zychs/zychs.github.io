◇ The One Job drift architecture

Everything in all three shells exists to do one thing: produce a drift metric and close a drift-correction loop — in every domain. sesefus doesn't contain the magnum opus; it feeds it. Every domain conforms to one uniform contract, so a new domain is a new folder, not a new architecture.

signal() → score() → correct()
The cull test — does this file either carry voice into the system, or produce, feed, or surface a drift signal sesephus can correct against? Yes → backbone, keep it. No → dead plumbing, cut it.

→ The Journey of One Memo the whole machine

One spoken thought, from your mouth to a trendable number. This is the road it travels — the reference implementation (ETDI, the affective domain) end to end.

  1. Speak
    you · 30s / 60s / 90s
    A check-in, a thought, a reflection. The raw material.
  2. Capture
    core/sesephus/src/client.zig · audio_record.zig
    The Zig edge client grabs audio through WinMM and streams WAV frames over TCP. (0.9.3-alpha ships with a Python + sounddevice capture path; the Zig engine stays the vision but doesn't gate shipping.)
  3. VaultTCP 5000 · HTTP 3000
    core/sesephus/src/host.zig · database.zig
    The host daemon seals it into sesephus_vault.db with ChaCha20-Poly1305. Your words never leave the machine.
  4. Transcribeport 3001
    dashboard/dashboard_server.py · Whisper (base)
    The Python bridge turns speech into text — plus timestamps that reveal pacing: words per second, pauses, hesitations.
  5. Infer
    tools/etdi_inference.py · Ollama on your 5080
    A locked prompt and a strict JSON schema force the model to answer only: valence, arousal, salience, and how likely this moment bent time.
  6. Score
    tools/etdi_pipeline.py → etdi.db + manifest
    One formula collapses the emotion into a density score, written beside the memo — in the database and inside its own manifest.
  7. Beholdport 5173
    dashboard/ui → sidebar → ETDI
    The React dashboard draws the daily trend and flags the heavy days. Where you stand and look back at the hill.

∿ The Signal — ETDI affective domain · reference impl

The Emotional Time Density Index: how much emotional charge is packed into each minute of speaking. Dense minutes are the ones that stretch, compress, or sit heavy in memory. The math is one decision ahead of the code — the norm formula is locked; the product formula is what still runs today.

ETDI = √(v² + a² + s²) ÷ (√3 × minutes) decided · not yet in code · flag ≈ 0.30–0.35  ·  shipped: (|v| × a × s) ÷ minutes · flag 0.15
Feel the metric — drag the sliders (norm formula)
0.360
heavy — flagged

Norm-formula bands: quiet < 0.12 · charged 0.12–0.32 · heavy ≥ 0.32.   Old product formula on the same inputs: 0.182.

Drift layer (v2) — the next step past a fixed threshold: an EMA baseline (η ≈ 0.9) + per-axis MAD σ, then flag when the Euclidean norm of the normalized residual exceeds τ ≈ 2 — “a two-sigma day for you.” Collapses back to the norm formula when there's no history yet.

⚠ The disclosure gate default: sealed never-measure-until-open

Any stigmatized signal (porosity, and others like it) is inadmissible until the user deliberately discloses — never scored, surfaced, or used to assume status. The system never opens the gate itself; an accidental utterance does nothing; once opened, disclosure is durable.

Three distinct mechanisms, and none is “revoke”: willingness backoff (automatic, temporary — “leave me alone right now”), durable disclosure (“remember I'm in recovery”), and hard erasure (deliberate, high-friction, separate). Willingness delivers the relief revocation reached for — so nothing traps the user, and nothing casually forgets them.

Traps to remember from the fact-check
  • All six manifests have durationSeconds: null — paste a transcript without a duration and ETDI divides by a 3-second floor and inflates wildly. Fill the duration first.
  • --wav prints the score but never saves the transcript — nothing to copy into a manifest until the backfill flag exists.
  • Manifests already name their audio — read source.sourcePath, don't hunt by date.
