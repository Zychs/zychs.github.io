Sesefus — Command Cheatsheet (editorial-stage ledger)

> snapshot: 2026-07-05 · source: "Quick CLI Ledgar for Editorial Stage" artifact; sourced from sesefus docs/CLI.md, docs/sesephus_help.md, src/main.zig — verified against code

Audio-first growth engine: circadian rhythm cues, encrypted voice journaling, Stoic reflection. Everything routes through the Zig CLI or its mirrored HTTP API. States: wired = real logic, works today · stub = parses, prints, no-op · legacy = kept for compat, phasing out.

Invocation & role — UNIFIED BINARY

One sesefus executable replaces the old host.exe / client.exe. First run prompts for a role and persists it to runtime.json, then self-restarts.

| Command | State | Notes | |---|---|---| | sesefus --role host\|client | wired | Scheduler daemon or edge listener; persisted after first pick | | sesefus --reset-role | wired | Clear saved role; next launch re-prompts | | sesefus --host <ip\|auto> --rescan | wired | Client target host; auto/rescan = LAN discovery on port 5000 | | sesefus --port <port> · --non-interactive · --no-record | wired | Client TCP port (def 5000); skip record prompt; disable mic |

Global flags — parsed by cli.zig ahead of every verb

--production (strict mode, destructive ops demand confirm) · --dry-run/-n · --json · --help/-h — all wired.

CLI verbs

| Command | State | Notes | |---|---|---| | status | wired | Engine state, connected clients, next rhythm cue | | journal record [minutes] | wired | Voice entry, defaults 3–10 min (core path) | | journal review last | wired | Play back most recent entry | | journal prompt stoic | wired | Spoken Stoic reflection prompt | | rhythm schedule morning\|evening | wired | Ritual alarm sequence per end of day | | rhythm next | wired | "What is my next growth anchor?" | | stoic daily-reflection | wired | Guided evening audio review | | stoic virtue-check <virtue> | wired | courage · wisdom · justice · temperance | | stoic obstacle | wired | Speak an obstacle, get reframing logic | | lead qualify --handle <user> | wired | POSTs prompts/qualify-post.md to LOCAL_LLM_URL (def :8000) | | lead mine stoic | stub | Print-only — logic still in host dispatcher | | lead feed journal | stub | Print-only | | vault status | wired | Fill level + metadata | | vault key-verify <hex> | wired | Check 64-char key against the vault | | vault backup [dest] | wired | Safe copy of encrypted DB | | vault ingest-archive --dry-run --limit N | wired | Shell the dual-archive Python ingress |

Host — direct flags (daemon)

--vault <path> (def V:\sesephus_vault.db → ./ fallback) · --read-vault (dump decrypted metadata, exit) · --extract <idx> <out.wav> — all wired.

Host shell (interactive REPL)

Alarms (actions: record_audio, play_sound): alarm <client> <sec> <action> <dur> · alarm_group · alarm_interval (count alarms spaced over dur) · alarm_adjust <parent> <spacing> <jitter_ms> · alarm_bulk · alarm_toggle true|false — all wired.

Subgroups: group_create <name> <ids> · group_rename · group_edit · group_delete — all wired.

Vault ops: vault_key_verify · vault_audit (tamper check) · vault_profile (r/w benchmark) · vault_refactor <dest> · vault_shuffle <dest> (randomize page layout) · vault_distribute <prefix> (shard by client ID) — all wired.

Storage & signal tooling (SSFS · ETDI)

**ssfs/drive-mapping.json is the single source of truth for drive letters — never hardcode V: / E: / T:.**

| Command | Notes | |---|---| | node ssfs/storage/config-engine.js | Verify drives by label, fail-loud, receipt → V:\ssfs-vault\state\ssfs-verified.json. Run before big ops | | python tools/ssfs_config.py | Print resolved cold-archive path + existence | | python tools/etdi_pipeline.py --backend grok | Memo → Whisper → emotion JSON → etdi.db (backends: ollama def · grok · lexical) | | GET /api/etdi/{trend,flags,entries} | Dashboard surfacing (EtdiPanel.jsx) |
