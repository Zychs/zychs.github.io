sesefus — the voice layer that measures drift and closes the loop

One container for everything we've decided: three nested shells, four buckets, and the invariants that keep the sensitive parts safe. This is the spec the fresh directory gets built against.

Everything in all three shells exists for one job: produce a drift metric and close a drift-correction loop, in every domain. sesefus doesn't contain the magnum opus — it feeds it.

Substrate

the layer itself — not domains
config / comprehension driftkeystone · #1 · unbuilt

Voice-native configuration that doesn't bore the user. Different users comprehend audio at different rates — so don't set the rate, measure the mismatch between delivery and comprehension (re-asks, latency, barge-in) and let it self-calibrate. Config becomes a drift signal like any other.

voice I/O

Capture and speak-back — the Zig client plus adaptive-rate delivery. The channel every domain talks through.

the vault

Encrypted local store (ChaCha20-Poly1305). Zig host is the source of truth for state.

the metric surface

Where drift is shown and spoken back — dashboard + voice. The place the loop reports to.

Cross-cutting services

used by every domain, owned by none
the domain contractsignal() → score() → correct()

The uniform plugin shape. Every drift domain conforms to it, so a new domain is a new folder — not a new architecture. ETDI is the reference implementation.

context sievewire the return

PCA (spiffy_prune / tapestry) — sieves everything down to usable tidbits before any domain scores it. "Worked ish, but never interfaced with its return." First task: surface its output.

disclosure gatesafety-critical

Gates sensitive domains behind explicit consent. Detailed below — five invariants, default state sealed.

hard erasure

A distinct primitive, not a gate state. Deliberate, high-friction total deletion — the honest escape hatch, kept hard so it's never a low-willingness impulse.

Correction

how a scored drift becomes an action
the loopmostly implicit today

Turns "you've drifted" into a cue, a prompt, or a schedule change. The least-defined bucket — it firms up once domains are actually emitting scores.

willingnessmodulator, not a domain

Governs how hard the loop pushes. Porosity feeds it: post-run, speech slows → willingness low → back off, don't nag. The gated signal's real job isn't to catch anyone — it's to stop pushing at the moment pushing would hurt.

⚠

The disclosure gate

inherited by any sensitive domain

Porosity — speech slowing as a post-run adrenaline tail fades — can indicate state, but only for a user who has said so. That rule isn't a porosity rule; it's a system primitive every stigmatized signal inherits. Tagged: disclosure-gated · durable · never-measure-until-open.

Gate invariants default: sealed policy: never-measure-until-open
  1. Detection ≠ permission.
    A sealed domain's signal is inadmissible — never scored, surfaced, spoken, or used to assume status. can-measure and may-use are decoupled.
  2. The system never opens the gate.
    It never initiates. It never says "you seem to be using." Disclosure is the user's act — the system only ever receives it.
  3. Opening requires deliberate, verified intent.
    An affirmative flow where it's unmistakable the user knows they're disclosing — a confirmation step, not a keyword trigger.
  4. Accidental utterance does nothing.
    If the info falls out in speech, the gate stays sealed. Overhearing is not consent.
  5. Disclosure is durable.
    Once made, it's remembered and acted on. It does not re-seal on impulse — holding it steady is the duty of care.
Three mechanisms — and why none of them is "revoke"
The needMechanismFriction
"Leave me alone right now"willingness backoff — automatic, temporarynone — it just happens
"Remember I'm in recovery"durable disclosure — the dutyopens once, stays
"Destroy the record entirely"hard erasure — deliberate, separateintentional, never impulsive

Willingness delivers the relief that revocation was reaching for — softly, automatically, without ever forgetting. So nothing traps the user, and nothing casually forgets them.
